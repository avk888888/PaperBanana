PaperBanana

輸入一段方法論的文字描述，自動生成論文風格的方法論示意圖。
本機執行、單一檔案、雙擊即開，支援多輪自我精煉。

Python Flask OpenRouter Gemini 2.5 Flash Windows 一鍵啟動

01這是什麼？

PaperBanana 是一套「論文插圖自動生成」工具。你不需要會畫圖或排版， 只要用自然語言描述你的方法流程，它就會產出一張可以直接放進論文的示意圖。

✍️

文字進，圖片出

中文或英文描述都可以。段落、Markdown 表格、甚至整篇方法論都能當輸入。

🔁

多輪自我精煉

每一次生成後會自我檢查並重畫，迭代次數可調（1～10 輪），越多次越精緻。

💻

完全在本機跑

用瀏覽器開本機的 5051 埠操作，資料不經過任何第三方伺服器，除了模型 API。

02它怎麼運作？

整個流程分四步，每一步都由大型模型驅動：

1

你輸入描述

在網頁介面的文字框寫下方法論內容，例如「我們提出一個具多頭注意力與前饋網路的分類模型」。

2

視覺規劃（Planner）

語言模型把抽象文字翻譯成一份「版面規劃書」：哪裡放哪個區塊、箭頭往哪走、用什麼配色。 使用的模型是 google/gemini-2.5-flash。

3

圖像生成（Visualizer）

圖像模型依規劃書把圖畫出來，使用 google/gemini-3.1-flash-lite-image。 這一步是整條流程中唯一會產生實際圖片的環節。

4

精煉迭代（Critic）

把剛生成的圖回頭對照原始描述，找出錯字、箭頭方向錯誤、擁擠的區塊， 改寫規劃書後重畫。重複到設定的次數為止，最後一輪的結果就是成品。

補充：這套流程源自 Google Cloud AI Research 與北京大學的論文 《PaperBanana: Automating Academic Illustration for AI Scientists》， 原框架共有五個角色（Retriever、Planner、Stylist、Visualizer、Critic）。 本專案是精簡後的單機版本，保留最核心的「規劃 → 生成 → 精煉」循環。

05怎麼在自己的電腦跑？

需要三個東西：Python 環境、一個 OpenRouter API Key、以及這個資料夾的檔案。

# 1. 安裝相依套件（只需做一次）
pip install flask paperbanana

# 2. 把 OpenRouter API Key 存成檔案
#    在資料夾裡建立 .openrouter_key，內容只放那一行金鑰
#    或把金鑰貼進 PaperBanana.py 最上面的 KEY_CONTENT 變數

# 3. 啟動（Windows 直接雙擊 PaperBanana.bat 也可以）
python PaperBanana.py

# 4. 瀏覽器會自動開啟 http://localhost:5051
#    輸入描述 → 設定 Refine 次數 → 按 Generate
重要：這一頁不能直接執行這個工具。 它是純靜態的展示頁面（只有 HTML 和圖片），沒有任何後端。 真正的生成功能需要本機的 Python 環境、以及你的 API Key， 這在 GitHub Pages 這類純靜態空間上是做不到的。
費用提醒：每次按下 Generate 都會實際呼叫 OpenRouter 並產生費用， 費用高低取決於 Refine 次數。次數越多，圖越細緻但花費也會等比增加。

06技術細節

元件選用用途
網頁框架Flask 提供單一頁面與 /api/generate 介面，跑在本機 5051 埠
生成框架paperbanana 套件 負責規劃、生成、精煉的完整流程編排
語言模型（VLM）google/gemini-2.5-flash 讀懂描述、規劃版面、檢查錯誤
圖像模型google/gemini-3.1-flash-lite-image 把規劃書實際畫成圖片
路由服務OpenRouter 用單一 API Key 呼叫上述兩種模型
輸出位置pb_output/runs/ 每次生成建立一個資料夾，保留各輪圖片與規劃紀錄
